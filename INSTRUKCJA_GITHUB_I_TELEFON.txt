PALETA MALARZA — AKTUALIZACJA GALERII KOMPOZYCJI

W paczce są:
- index.html — zaktualizowana aplikacja;
- sw.js — nowa pamięć podręczna PWA v13;
- 53 osobne ilustracje JPG;
- manifest PWA, ikony i .nojekyll.

JAK WGRAC NA GITHUB:
1. Rozpakuj ZIP.
2. Otwórz repozytorium alutka411-ui/paleta-malarska.
3. W głównym katalogu (root) wybierz Add file → Upload files.
4. Przeciągnij całą zawartość rozpakowanego folderu.
5. JPG muszą leżeć luzem obok index.html — nie wkładaj ich do folderu.
6. Zastąp dotychczasowe index.html oraz sw.js.
7. Zatwierdź przyciskiem Commit changes.

WAŻNE:
- Nie twórz folderu kompozycje-mini.
- Nie przenoś nowych plików JPG do podfolderu.
- Nie usuwaj manifest.webmanifest, ikon ani .nojekyll.
- Stare, nieużywane grafiki mogą zostać w repozytorium; nowa galeria korzysta wyłącznie z 53 nowych plików.
- GitHub Pages powinien publikować gałąź main, katalog /(root).

INSTALACJA NA TELEFONIE:
Android: Chrome → menu ⋮ → Zainstaluj aplikację / Dodaj do ekranu głównego.
iPhone: Safari → Udostępnij → Dodaj do ekranu początkowego.
PWA instaluje się z opublikowanego adresu HTTPS, nie z lokalnego pliku index.html.
